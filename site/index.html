    Desktop app

    Prefer a regular program? Download DocShift for your computer. It works fully offline and can open files directly from your file manager.

    Windows macOS Linux (AppImage) Linux (.deb)
    First launch: security prompts
    • Windows: if "Windows protected your PC" appears, click More info → Run anyway.
    • macOS: open the downloaded file and drag DocShift to Applications. The first time you open it, macOS says it can't verify the developer. Open System Settings → Privacy & Security, scroll down and click Open Anyway.
    • Linux (AppImage): make the file executable (right-click → Properties → Allow executing, or chmod +x DocShift-Linux.AppImage), then run it. The .deb installs with sudo apt install ./DocShift-Linux.deb.

    These prompts appear because the app isn't signed with a paid developer certificate. The source code is public on GitHub.

    What converts to what

    Documents

    Pages, Word (.docx), PDF, OpenDocument (.odt), RTF, EPUB, HTML, Markdown, plain text, LaTeX, reStructuredText, Org, AsciiDoc, Jupyter, Typst

    → Word, PDF, OpenDocument, RTF, HTML, Markdown, text, EPUB, LaTeX, PowerPoint, Excel, CSV

    Presentations

    Keynote, PowerPoint (.pptx), OpenDocument (.odp)

    → PowerPoint, PDF, Word, OpenDocument, HTML, Markdown, text

    Spreadsheets

    Numbers, Excel (.xlsx, .xls, .xlsb), OpenDocument (.ods), CSV, TSV

    → Excel, CSV, PDF, OpenDocument, Numbers, TSV, HTML, JSON, Word, Markdown, text

    Images

    PNG, JPEG, WebP, GIF, BMP, SVG, AVIF

    → PNG, JPEG, WebP, PDF

    Good to know
    • Text, headings, lists, tables and images carry over between Word, OpenDocument, Markdown, HTML and similar formats. Exact page layout, fonts and colors may change.
    • Pages, Keynote and PDF files are converted as text. Layout and pictures are not kept. Scanned PDFs (pictures of text) have no text to extract.
    • Spreadsheet formulas are converted to their values in some formats (CSV, PDF, Word).
    • PDF output uses one standard font that covers Latin, Greek and Cyrillic text, but not Chinese, Japanese or Korean.
    • Old binary .doc and .ppt files are not supported. Save them as .docx/.pptx first.
    • The document engine (pandoc, about 16 MB) downloads once, the first time you need it. After that, DocShift works offline.
    • Install DocShift as an app with the Install app button (Chrome, Edge, Android), or on iPhone/iPad with Share → Add to Home Screen. The installed app can open files directly and, on Android, receive files shared from other apps.
